# FontAwesome 图标白名单 · 保险清单
#
# 本文件是手工维护的"常用图标"补充集，目的是：即使源码/后台暂时没用到某个图标，
# 它也被包含在子集字体里，避免以后新增图标时出现豆腐块。
#
# 维护约定：
#   - 一行一个图标类名（fa-xxx），# 开头为注释
#   - 新增图标后无需手动重跑裁剪，只需在此追加，然后执行：
#       python tools/fa-subset.py
#   - 类名必须真实存在于 assets/fonts/fa/all.min.css，否则会在校验阶段被剔除
#     （用 tools/fa-collect.py 可以看到被剔除的名单）
#
