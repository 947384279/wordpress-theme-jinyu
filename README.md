## 核心特性

### 外观与版块
- **暗色模式**：手动切换 +「跟随系统」自动切换，正文字号可调节。
- **首页头部版块**：幻灯片 / 四宫格 / 分类两栏，可视化配置即开即用。
- **25+ 短代码**：卡片、提示框、分栏、按钮等组件即插即用，兼容古登堡区块。

### 文章体验
- **文章互动**：点赞、收藏、分享、海报生成、二维码。
- **文章增强**：目录 (TOC)、面包屑、返回顶部、代码高亮、阅读进度、相关文章、上一篇/下一篇。
- **评论体验**：邮件通知、UA 解析、表情选择器、防暴破限流、评论分页。

### 内容与维护
- **自定义内容**：内置「动态 / 友链」文章类型与「系列」分类法。
- **维护模式**：一键维护页；统计代码独立字段，内置访问统计面板。
- **一键更新**：接入 WP 原生主题更新通道，RSA 签名 + sha256 校验。

## 用户与社区

- **用户中心**：登录/注册弹窗、找回密码、验证码策略、登录防暴破（5 次锁 15 分）、前台投稿（待审核）。
- **第三方登录**：QQ / GitHub / Gitee 一键登录。
- **实时搜索**：输入即出下拉建议（封面 + 日期 + 阅读时长）。
- **邮件订阅**：短代码 + 小工具，后台可导出 CSV。
- **外链中转**：防权重流失 + 点击统计。
- **小工具套件**：作者卡 / 热门 / 标签云 / 最新评论 / 相关 / 实时概况。
- **URL 优化**：支持去除 `/category/` 分类前缀。

## SEO 与流量

- 结构化数据（Open Graph / JSON-LD：Article · Breadcrumb · FAQ · HowTo）
- 自动内链、长尾词覆盖
- `llms.txt` / `llms-full.txt`（GEO / Agent 友好）
- IndexNow 实时推送、百度主动推送
- 归档页标题优化、内置访问统计

## 性能与安全

- **双层缓存**：Memcached 对象缓存 + WP Super Cache 整页静态（暖缓存 0 SQL）
- **资源优化**：脚本 defer、HTML 压缩、WebP + 懒加载 + LQIP、封面批量预热无 N+1
- **封面健壮性**：无图文章按所属分类自动取类目默认封面；外链封面死图自动探测（GET + Range，结果缓存 12h）并回退类目封面，杜绝裂图
- **安全**：RSA-2048 签名更新 + 包 sha256 校验、SQL 全部参数化、输出全程转义、ABSPATH 守卫

## 安装

1. 下载主题压缩包（见下方「获取」）。
2. 后台 **外观 → 主题 → 上传主题**，选择 `jinyu.zip` 并启用。
3. 后台 **外观 → 金玉设置** 打开可视化配置中心，按需开启功能。

> 环境要求：PHP 8.0+，WordPress 6.0+，推荐开启对象缓存与整页缓存。

## 配置中心

19 个设置分组：全局 / 基础 / 风格 / 页脚 / 幻灯片 / 内容 / 用户 / SEO / 资源 / 存储 / 邮件 / AI / 销售 / 扩展 / 关于 等。

- 支持 **导入 / 导出 JSON** 配置备份
- 单组「重置本组」，不影响其它设置
- 敏感字段（邮箱密码等）密文存储

## 更新

本主题通过 **WordPress.org 官方渠道** 分发与更新：在后台「外观 → 主题」中检测到新版本后一键升级，无需手动下载。

## 常见问题

**Q：支持哪些 WordPress / PHP 版本？**
A：WordPress 6.0+、PHP 8.0+。

**Q：如何更新主题？**
A：通过 WordPress.org 官方渠道自动更新，后台检测到新版本后一键升级。

**Q：暗色模式怎么切换？**
A：默认「跟随系统」，也可在配置中心改为固定亮色 / 暗色，或提供前台手动切换按钮。另有「暗色配色方案」可选默认深灰或纯黑（OLED 更省电、对比更强），该选项只在暗色模式下生效——亮色模式下切换它不会有任何变化。

**Q：短代码兼容古登堡区块编辑器吗？**
A：兼容。常用短代码提供区块编辑器快捷插入入口。

**Q：更新安全吗？会被篡改吗？**
A：更新源经 RSA-2048 签名校验，更新包带 sha256 校验，签名或哈希不符则拒绝升级。
